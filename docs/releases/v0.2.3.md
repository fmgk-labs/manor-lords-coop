Manor Lords Co-op 0.2.3 for Manor Lords 0.8.117 (Steam).

**Every player needs this same version.** A copy on another version is refused at the join. Install it the same way as before: unzip into `Manor Lords\ManorLords\Binaries\Win64` and overwrite.

## New in 0.2.3

- Host New Game: the host now prepares a new game once before friends load it (a short save and load of a few seconds, with a message). This removes the resync loop seen on new games.
- A resync loop breaker: when the same difference is still there after every copy has loaded the host's save, the mod stops loading for that kind of difference for 15 minutes and shows one message, instead of resyncing again and again.
- The host's Main Menu and Quit Game buttons ask for a second click while friends are in the game ("Ends co-op: click again"), so a mis-click no longer ends the game for everyone.
- A host whose Steam connection dropped can invite its friends back: Invite Friends makes a new lobby when the old one is gone.
- A friend can join again without restarting the game after a session ended.
- The menu button no longer stays on "the host left the game": it goes back to "Co-op" after 20 seconds or when the panel is opened.
- A join is no longer bounced when Steam reports "idle" for a moment right after joining.
- Short connection cuts on the host's side: the friend's game pauses with "Host connection lost" for up to 30 seconds and carries on when the host is back, instead of leaving at once.
- Two connection drops close together no longer make every player reload.
- A second copy of the game started on the same PC during a session no longer disturbs the first one. It shows "Manor Lords is already running with co-op on this PC. Close this copy."
- Checks at the start of a session no longer depend on the two PCs' clocks agreeing.
- The bug report zip now also holds the Steam link's log (player names and Steam ids are removed) and says which game process wrote each file.

## How it was tested

- Two game copies on one PC: joins, single reloads, resyncs, a full rejoin, about 150 game days at speed 4 and 8 with no resync asked and no crash.
- The clean zip, installed as a player does, with real mouse clicks: the Co-op panel, Host From Save, the bug report button, the Main Menu and Quit Game guard.
- **Not tested yet over real Steam between two PCs:** the new lobby after a dropped Steam connection, the invite after it, the 30 second pause on a short cut, and a real second start of the game. Please report what you see.
